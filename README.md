# Realm drop reference

Searchable reference for the current server content snapshot, 4 October 2026.

**Website:** https://zosyn-j.github.io/realm-drop-reference/

Includes 651 NPC templates, 220 random pools, 10 numbered treasure tables, chest rules and quest rewards. Search by creature name, item name or internal class code. The download contains the full CSV tables and mechanics guide.

Inventory-generation odds, conditional pool odds and level/value-table membership are different measurements. Runtime context and scripted conditions can affect actual drops. See the included mechanics guide; not every outcome has an exact per-kill probability.

This repository contains only the static reference and downloads, not server source, player accounts or deployment configuration. No analytics or external scripts.

## Dungeon containers

The **Chests & bone piles** tab links 1,101 declared content slots to 342 placed containers. It includes ordinary owner-linked items, pool links, lock settings and instance overrides. Four ambiguous Zoo NPC-owner references are retained as extraction notes instead of guessed assignments.
